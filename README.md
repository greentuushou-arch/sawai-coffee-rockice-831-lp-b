内容は [sawai-coffee-rockice-831-lp](https://github.com/greentuushou-arch/sawai-coffee-rockice-831-lp)(デザインA)と同一(8月31日限定、2セット購入でもう1セットプレゼント、ポイント2倍)ですが、**配色・レイアウトの組み方(フレームワーク)をデザインAとは別系統で作った別バージョン**です。デザインAはそのまま残し、こちらは並行して比較・選択いただくためのものです。

※最初はチャコール×アンバーの落ち着いたエディトリアル系トーンで作成しましたが、「キャンペーンらしいお得感・イベント感が欲しい、もっとパキッとした感じに」というフィードバックを受け、**赤×黄×焦茶のセールらしい配色**と**ゴシック太字中心のタイポグラフィ**に作り直しています。

## 重要:このキャンペーンの仕組み(デザインAと同一)

1. お客様がこのページでクーポン(3,238円OFF)を獲得
2. 商品ページで**数量を「2」**にして購入手続き(通常価格 3,238円×2＝6,476円)
3. 会計画面でクーポンが適用され、支払額が **3,238円** になる(＝2セット/100袋が届く)

**数量が「1」のままだとクーポンを使っても意図した「もう1セット無料」にはなりません。** クーポンの割引設定(3,238円OFF・最低購入金額など)を楽天RMS側でも「数量2以上」の条件が付けられるかご確認のうえ設定してください。

デザインAと同じ設定項目です。`index.html` 内 `<script>` タグの以下を編集してください。

```js

const SOLD_COUNT = 0;         // 現在の販売セット数(0のあいだは非表示)
```

カウントダウンは2026年8月31日 0:00〜23:59に設定済みです。

## 実装上のご注意

- JavaScriptを使用しています(カウントダウン・クーポンURL一括設定・販売実績表示)。
- スマホ表示を基準に作成し、768px以上でPC向け2カラムレイアウト(ファーストビューの左右分割・ステップの3カラム表示など)に切り替わります。
- Google Fonts(Zen Kaku Gothic New / Josefin Sans)を外部読み込みしています。
- 紙吹雪演出の代わりに、赤地に流れるマーキー帯(2箇所)とクーポンボタンの脈動アニメーションで動きを出しています。
