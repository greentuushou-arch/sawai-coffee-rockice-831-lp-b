## 現行版のコンセプト

「8月31日の1日だけ、澤井珈琲がちょっとおかしなほどお得になる」イベント感を最優先。ご提供いただいた参考画像(生成り地+手描き風ブルーの線画イラスト+赤・黄のアクセント)のテイストを、ページ全体の配色・雰囲気に反映しています。

- **配色**: 生成り(`#F7F1E2`)を土台に、ブルー(`#2455D6`)・レッド(`#E63328`)・イエロー(`#FFCC33`)の3色を大胆に使用。以前の紺(ほぼ黒)を基調にした暗いSALE広告トーンから、参考画像に近い明るいポスター調に変更しました。両脇の背景もブルーに変更しています。
- **ファーストビュー**: **コピー・価格・イラストをすべて含んだ1枚のポスター画像**に変更しました。画像の下にはカウントダウンとクーポン獲得ボタンのみHTML表示されます(この2つは実際の日時・リンクと連動する必要があるため、画像化していません)。
- **情報の優先順位**: 「2セット目無料」を最大の訴求として最も大きく、次に「8.31限定」「6,476円→3,238円」、ポイント2倍・送料無料はその次に扱っています。
- **セクションごとに景色を変更**: ①ファーストビュー(1枚のポスター画像)→②商品紹介(生成り〜白・爽やか)→③お得説明(ブルー×赤ストライプのSALE広告テンション、巨大な「2 SET」表記と実質50%OFFのスタンプバッジ)→④購入方法(白背景・装飾を抑えた明確な3ステップ図解)→⑤レビュー(静かな配色で信頼感)→⑥ラスト(赤地に「LAST CHANCE」「2セット目無料」を再度巨大に)、という強弱の波を作っています。
- **フォント**: 日本語=Zen Kaku Gothic New(太字900中心)/ 数字・英字=Barlow(価格など正確に読ませたい数字)・Barlow Condensed(8.31などの大型見出し数字・英語ラベル)/ 手描き風の一言のみYusei Magic。数字と漢字が混在する箇所(「6,476円」など)は文字単位でフォントを分けて書体の切れ目が不自然にならないようにしています。

## 重要:このキャンペーンの仕組み(デザインAと同一)

1. お客様がこのページでクーポン(3,238円OFF)を獲得
2. 商品ページで**数量を「2」**にして購入手続き(通常価格 3,238円×2＝6,476円)
3. 会計画面でクーポンが適用され、支払額が **3,238円** になる(＝2セット/100袋が届く)

**数量が「1」のままだとクーポンを使っても意図した「もう1セット無料」にはなりません。** クーポンの割引設定(3,238円OFF・最低購入金額など)を楽天RMS側でも「数量2以上」の条件が付けられるかご確認のうえ設定してください。

## 実装上のご注意

- JavaScriptを使用しています(カウントダウン・クーポンURL一括設定・販売実績表示)。
